I joined Flutterwave in July 2019 to improve relations with the developer community and to write technical content on Flutterwave's payment gateway.

## Technical writing for fintech audiences

I wrote tutorials on building API-based applications for card payments, bank transfers, refunds, chargebacks, and virtual wallets, in several programming languages. I also documented part of the endpoints for Flutterwave's v3 API, which was built on ReadMe.

Improving the developer experience of the v3 endpoints, together with new payment features for small businesses and individuals, increased usage of Flutterwave's API by <mark>45%</mark>.

## Technical account management

During the pandemic I also worked as a technical account manager for tier one accounts such as Uber Africa and Flywire. I analysed their payment data, defined technical requirements for new products and features with the product management team, and led the integration of a new payment method on the gateway.

The role sharpened my documentation skills too:

- I created knowledge bases that brought new members of the technical account management team up to speed and reduced friction during handovers.
- I set up personalised user guides for each tier one business in the portfolio.
- I created a documentation framework for pre-mortem and post-mortem reports on service disruptions, which indirectly helped reduce customer drop-off by <mark>8%</mark>.

## Developer community

I partnered with peer tech companies to run hackathons where university developers built projects on Flutterwave's APIs.
